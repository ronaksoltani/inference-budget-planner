# Contributing

Thanks for reviewing this project. Contributions should keep it useful, accessible and local-first.

## Getting started

- Open index.html in a modern browser or serve the folder with python -m http.server 8000.
- Keep the project free of API keys, analytics and external services.
- Use fictional sample data and do not include private customer information.

## Changes

- Preserve keyboard access, visible focus and reduced-motion support.
- Keep rules and calculations understandable in code and documentation.
- Explain new assumptions and update the README when behavior changes.
- Prefer focused changes that preserve the zero-dependency setup.

## Reporting an issue

Include browser, steps to reproduce, expected result and actual result. Remove secrets and personal data from examples.
